# IAE-LSD-KL-PSD
Used an IAE-LSD-KL model to discriminate between neutron and gamma ray pulses.
Background: 
modern nuclear reactors depend heavily on Gamma Ray and Neutron discriminations to give accurate and reliable data on the reactions happening inside the reactor. 
Goal:
being able to take in real neuron reactions and game ray waves and discriminate between them sophisticatedly
